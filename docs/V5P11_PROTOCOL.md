# V5-P11 protocol freeze

V5-P11 is a new versioned synthetic study. Historical `CV001`–`CV004` and all
previous reports/runs are immutable and are never pooled with `IV001`–`IV004`.

The main worlds are balanced: IV001 and IV003 have a public source generated by
the same mechanism family as the target; IV002 and IV004 have a different source
mechanism. Public target/source initial state, rate, noise, time units and
variable mapping are explicit. Private truth and oracle scores are never sent to
an agent. The public candidate menu is the existing eight-action menu.

The frozen seed is `20261113`, with world offsets `1101, 2203, 3307, 4411`.
The main plan uses worlds in the fixed order IV001, IV002, IV003, IV004 and
replicates R0 then R1. Conditions are ordered A, B, C.Stage1, C.Stage2,
D.Stage2. A receives target only; B receives target plus the related source;
C and D receive the same Stage1 raw response; D receives a router-generated
neutral artifact with source/evidence fields removed. Stage1 has no action menu.

The primary endpoint is action score C−D, with zero distinct from undefined.
Secondary endpoints are B−A, information-gain selected, raw Agent numerical
accuracy, calculator-assisted accuracy, Stage1 relation/law/mapping accuracy,
and strict scientific validity. Numerical tolerance is 0.02. Raw and assisted
metrics are never substituted for one another. Statistics are descriptive and
clustered by the four worlds; two repeats do not count as two independent
scientific worlds.

The paid plan is 40 unique requests: four worlds × two repeats × five requests
(A, B, one shared Stage1, C Stage2, D Stage2). Serial execution and zero
automatic retries are mandatory. The local usage estimate cap is USD 0.40;
provider billing is recorded as null when not verified.
